Datenschutzerklärung

Stand: 18. November 2026 · English version below

Wer die Anwendung nutzt

„meeramics“ ist ein privates Werkzeug der Inhaberin bzw. des Inhabers des Instagram-Kontos @meeramics. Es wird nur mit dem eigenen Google-Konto verwendet; Daten anderer Personen werden nicht abgefragt.

Welche Daten verarbeitet werden

Über die Google Drive API greift die Anwendung auf Dateien im eigenen Google Drive zu – hauptsächlich Videos, Fotos und Dokumente im Ordner „meeramics“. Weitere Daten (z. B. Kontakte, E-Mails, Standort) werden nicht abgefragt.

Wozu die Daten verwendet werden

Ausschließlich, um eigene Videos herunterzuladen, für Instagram zu bearbeiten und die Ergebnisse wieder im eigenen Drive zu speichern.

Weitergabe und Speicherung

Die Daten werden nicht verkauft, nicht zu Werbezwecken genutzt und nicht an Dritte weitergegeben. Die Bearbeitung findet in einer privaten Cloud-Arbeitsumgebung statt; Arbeitskopien werden dort nur vorübergehend gespeichert. Veröffentlicht werden nur Inhalte, die die Inhaberin bzw. der Inhaber selbst freigibt.

Google API

Die Nutzung von Daten, die über Google APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

Privacy Policy

Last updated: 18 November 2026

Who uses the application

“meeramics” is a private tool of the owner of the Instagram account @meeramics. It is used only with the owner’s own Google account; no data of other people is requested.

What data is processed

Through the Google Drive API the application accesses files in the owner’s own Google Drive – mainly videos, photos and documents in the “meeramics” folder. No other data (e.g. contacts, emails, location) is requested.

How the data is used

Only to download the owner’s own videos, edit them for Instagram and save the results back to the same Drive.

Sharing and storage

Data is not sold, not used for advertising and not shared with third parties. Editing takes place in a private cloud work environment; working copies are stored there only temporarily. Only content approved by the owner is published.

Google API

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
